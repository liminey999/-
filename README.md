# Игра «Кликер» (Clicker Game)

Интерактивная игра в жанре кликер, где игрок зарабатывает очки (монеты) за клики по главному объекту и тратит их на покупку улучшений для ускорения прогресса.

## Задание
Разработать графическую или веб-игру «Кликер». Игрок должен нажимать на центральный элемент (кнопку/персонажа) для получения игровой валюты. Накопленные средства можно тратить в магазине улучшений на увеличение дохода за один клик и покупку автокликеров, которые приносят пассивный доход каждую секунду.

## Требования к программе

### Функциональные требования
* **Механика клика:** при нажатии на главный объект баланс игрока увеличивается на текущее значение силы клика (изначально +1 монета).
* **Отображение статистики:** на экране в реальном времени отображаются текущий баланс, доход за клик и пассивный доход в секунду.
* **Магазин улучшений:**
  * *Усиление клика* — увеличивает количество монет за одно нажатие.
  * *Автокликер* — автоматически начисляет монеты каждую секунду без участия игрока.
* **Динамическая цена:** стоимость каждого улучшения растет после каждой покупки (например, на 15–20%).
* **Сохранение прогресса:** автоматическое сохранение баланса и купленных улучшений при выходе из игры и их загрузка при следующем запуске.
* **Визуальный отклик:** анимация нажатия на главный объект и блокировка кнопок покупки, если у игрока не хватает монет.
